# Support

Use GitHub Issues for reproducible defects and feature proposals after searching existing issues.
Include the GAssetForge version/commit, Windows version, workflow, reproduction steps, and sanitized
logs.

Please do not post:

- MCP Bearer tokens or environment-variable values;
- private Codex task/thread data;
- proprietary prompts, style references, or generated artwork without permission;
- full user directory paths when a redacted path is sufficient.

General Codex, OpenAI account, billing, or model availability questions belong in the relevant
OpenAI support channel. Security reports must follow [SECURITY.md](SECURITY.md).
